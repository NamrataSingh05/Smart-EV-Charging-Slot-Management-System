# Smart-EV-Charging-Slot-Management-System
IoT-based EV charging slot monitoring and reservation system using Raspberry Pi, RFID authentication, OLED display, and a real-time web dashboard.

# Smart EV Charging Slot Management System

## Overview
A Raspberry Pi based IoT system that monitors EV charging slot occupancy and provides real-time charging station status through a web dashboard.

The system uses RFID authentication for user access and updates charging slot availability dynamically.

## Features
- Real-time slot monitoring
- RFID based user authentication
- OLED status display
- Web dashboard
- Charging slot occupancy detection
- Visual and audio notifications

## Hardware Used
- Raspberry Pi
- RC522 RFID Reader
- RFID Tags
- OLED Display
- LEDs
- Buzzer
- Breadboard and jumper wires

## Software Used
- Python
- Flask
- HTML/CSS
- Raspberry Pi OS

## Working
1. User scans RFID card.
2. System verifies user access.
3. Charging slot status is updated.
4. Dashboard displays available and occupied slots.
5. OLED shows charging information.

## Applications
- Smart EV Charging Stations
- Smart Parking Systems
- Smart City Infrastructure
